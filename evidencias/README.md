# Evidências publicadas

Esta pasta contém apenas as seis capturas publicadas na apresentação do portfólio, com `MANIFESTO.csv` e SHA-256.

As evidências completas das 30 entregas permanecem na árvore local do projeto e não são distribuídas aqui. Por isso, `ferramentas/validar_progresso.py` reporta as pastas `evidencias/OTD-NNN/` ausentes quando executado somente com este subconjunto público.
